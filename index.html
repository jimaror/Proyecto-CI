📘 Aprendiendo Git

Bitácora personal del curso de Git y GitHub

2.1 Instalación y configuración

✅ Instalé Git en mi computadora y configuré mi identidad para poder trabajar.

git config --global user.name "Tu Nombre"
git config --global user.email "tu@email.com"

Para verificar que quedó bien configurado:

git config --list

2.2 Mi primer repositorio

✅ Con el comando git init creé un repositorio nuevo, que genera automáticamente la carpeta oculta .git donde Git guarda todo el historial.

Estados de los archivos en Git:

🔍 Untracked — El archivo es nuevo, Git no lo sigue todavía.
✏️ Modified — El archivo ha sido cambiado pero no guardado.
📥 Staged — El archivo está listo para ser confirmado.
✅ Committed — El cambio ya está guardado en el historial.
